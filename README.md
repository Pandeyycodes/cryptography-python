Was studying cryptography and thought I'd try implementing some of the algorithms in Python

- Caesar
- Vigenère
- Playfair
- Hill
- Diffie-Hellman
- RSA
- SHA

Planning to keep adding more as I learn ECC, DES, AES, digital signatures etc.
